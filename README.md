# AI Translate English Swahili

This example demonstrates AI machine translation using a pre-trained model. It translates English text into Swahili, one of the key Kenyan languages discussed in the article. The script highlights how AI can bridge language barriers, while also implicitly pointing to the challenges of model availability for less-resourced languages.

## Language

`python`

## How to Run

1. Ensure Python 3 is installed.
2. Install required libraries: `pip install transformers torch`
3. Run the script: `python main.py`
